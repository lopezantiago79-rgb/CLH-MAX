\begin{abstract}
We propose CLH-MAX, a Module-LWE-based key encapsulation mechanism (KEM) in the style of Kyber/ML-KEM in which the ring $\Z_q[X]/(X^{256}+1)$ is replaced by $\Rq=\Z_q[X]/\Phi_{257}(X)$, the ring of the prime cyclotomic field $\mathbb{Q}(\zeta_{257})$. For primes $q$ that are primitive roots modulo $257$ the polynomial $\Phi_{257}$ is irreducible modulo $q$, so $\Rq\cong\F_{q^{256}}$ is a field. We specify the CPA-secure public-key encryption layer, its Fujisaki--Okamoto transform to an IND-CCA2 KEM (random-oracle model), and three parameter sets of module rank $2,3,4$. We give a game-hopping proof that IND-CPA security reduces to the decision Module-LWE problem over $\Rq$, an exact analysis of the decryption failure probability (which corrects the na\"ive coefficient-variance count for this ring and shows that the ML-KEM modulus $q=3329$ is not adequate for rank $4$), validated by Monte Carlo simulation down to tail probabilities of about $10^{-5}$, a rigorous Chernoff bound on this probability that needs no independence assumption (evaluated with interval arithmetic), a choice of the modulus per module rank so that the rigorous bound is below $2^{-128}$ for all three sets, lattice-estimator outputs for key- and message-recovery instances (identical to ML-KEM-768 for $k=3$, and within about $0.4$ and $3.1$ bits of the weakest ML-KEM instances for $k=2$ and $k=4$), and a discussion of arithmetic cost: there is no NTT modulo $q$, but exact products can be computed with an NTT over an auxiliary prime because one operand is always small. We make no claim of higher concrete security than ML-KEM; the contribution is a fully specified alternative ring instantiation together with its correctness and reduction analysis, reproducible scripts, and a clear list of open problems.
\end{abstract}

\noindent\textbf{Keywords.} lattice-based cryptography, post-quantum cryptography, key encapsulation mechanism, Module-LWE, cyclotomic rings, decryption failure.

\noindent\textbf{Status.} This is an unrefereed technical note; it has not been peer-reviewed. Its claims are limited to what is proved or computed in the text and in the accompanying scripts. CLH-MAX has not been analysed by the community, its reference implementation is not constant-time, and it must not be used to protect real data; standardised schemes such as ML-KEM should be used instead.

\section{Introduction}
ML-KEM (FIPS~203 \cite{FIPS203}) is based on Module-LWE over $\Z_{3329}[X]/(X^{256}+1)$, a power-of-two cyclotomic ring chosen because it admits a fast (incomplete) number-theoretic transform (NTT). The choice of ring in structured-lattice cryptography is a design parameter that is not fully explored: other cyclotomic rings have been proposed, e.g.\ the prime-conductor rings $\Z_q[X]/\Phi_{n+1}$ ($n+1$ prime) used in the NIST round-2 candidates Round2 and Round5 \cite{Round5}. This note studies one concrete alternative, conductor $257$ (the Fermat prime $F_3=2^8+1$), for which the ring degree is $\varphi(257)=256$, equal to that of ML-KEM, so module ranks, key sizes and noise parameters can be compared directly.

\paragraph{Contributions.}
(1) A complete specification of CLH-MAX: PKE, FO-based KEM, three parameter sets (Sections~\ref{sec:ring}--\ref{sec:scheme}). (2) A proof that IND-CPA security reduces to two decision-MLWE instances over $\Rq$, with the explicit simulators (Section~\ref{sec:sec}, Appendix~\ref{app:sim}); the game-hopping inequality is machine-checked in Lean~4 for arbitrary module rank (Section~\ref{sec:artifact}). We also state an explicit IND-CCA2 bound in the random-oracle model (Theorem~\ref{thm:cca}), obtained from \cite{HHK17} with its hypotheses checked for this scheme. (3) An exact decoding threshold, an exact computation of the decryption failure probability including the ring-specific coefficient count for $\Phi_{257}$, and a rigorous Chernoff bound (with interval-arithmetic evaluation) that needs no independence assumption; they show that with the ML-KEM modulus $q=3329$ the rank-4 set does \emph{not} reach $2^{-128}$, which we repair by choosing the modulus per rank (Sections~\ref{sec:dfp},\ref{sec:params}, Appendices~\ref{app:count},\ref{app:script}). (4) A cost analysis of multiplication in $\Rq$ (Section~\ref{sec:arith}). (5) A check of the hypotheses of the known ring-specific attacks on RLWE/PLWE, showing why they do not apply to the field ring $\Rq$ (Section~\ref{sec:ringsec}).

\paragraph{Non-claims.} We do not claim that CLH-MAX is more secure than ML-KEM, that known attacks on ML-KEM fail to apply to a field ring, or that worst-case reductions give concrete security at these parameters. Section~\ref{sec:sec} explains why.

\paragraph{Related work.} Ring-LWE over general cyclotomic rings was introduced in \cite{LPR13}, including the worst-case reduction for arbitrary cyclotomic fields. Kyber \cite{BDKLLSSS18} and ML-KEM use module structure over $\Z_q[X]/(X^{256}+1)$; the module variant over $\Z_q[X]/\Phi_{257}$ studied here follows the same template. Prime-conductor cyclotomic rings were already used in Round5 \cite{Round5}, which is based on ring learning with rounding; we make no claim of novelty for the ring itself. Subfield and structural attacks are discussed in \cite{ABD16,CJL16,CDPR16,CDW17}.

\section{Preliminaries}
\paragraph{Notation.} $N=256$, $q$ prime, $\Rq=\Z_q[X]/\Phi_{257}(X)$ with $\Phi_{257}=X^{256}+\dots+X+1$. Elements are identified with coefficient vectors in $\Z_q^{256}$. For $k\ge1$, vectors and matrices over $\Rq$ are written with the module rank $k$ as dimension. $\psi_\eta$ is the centered binomial distribution on $\Z$: $\sum_{i=1}^{\eta}(a_i-b_i)$ with $a_i,b_i\leftarrow\{0,1\}$ uniform; it has variance $\eta/2$. For $\eta=2$ the variance is $1$ (we use $\eta=2$ throughout, so $\sigma^2=1$). $\chi$ denotes $\psi_2$ applied coefficient-wise.

\begin{definition}[Decision MLWE]
Let $n,m\ge1$. $\mathrm{MLWE}_{n,m,\chi}$ asks to distinguish $(B,Bs+e)$ from $(B,w)$, where $B\leftarrow U(\Rq^{m\times n})$, $s\leftarrow\chi^n$, $e\leftarrow\chi^m$, $w\leftarrow U(\Rq^m)$. $\mathrm{Adv}^{\mathrm{MLWE}}_{n,m,\chi}(\mathcal D)$ is $|\Pr[\mathcal D(B,Bs+e)=1]-\Pr[\mathcal D(B,w)=1]|$.
\end{definition}

\begin{definition}[PKE, IND-CPA]
A PKE is $(\mathsf{KeyGen},\mathsf{Enc},\mathsf{Dec})$. In the IND-CPA game the challenger samples $(pk,sk)$ and a bit $b$; the adversary picks $m_0,m_1$ of equal length, receives $\mathsf{Enc}(pk,m_b)$ and outputs $b'$. The advantage is $|\Pr[b'=b]-\tfrac12|$.
\end{definition}

\begin{definition}[KEM, IND-CCA2]
A KEM is $(\mathsf{KeyGen},\mathsf{Encaps},\mathsf{Decaps})$, with $\mathsf{Encaps}(pk)\to(c,K)$. In the IND-CCA2 game the adversary receives $(c^*,K_b)$ with $K_0$ the real key and $K_1$ uniform, and may query $\mathsf{Decaps}$ on any $c\neq c^*$; advantage $|\Pr[b'=b]-\tfrac12|$.
\end{definition}

\section{The ring}\label{sec:ring}
\begin{proposition}\label{prop:irr}
Let $q\ne257$ be prime. Then $\Phi_{257}$ is irreducible over $\F_q$ if and only if $\mathrm{ord}_{257}(q)=256$, i.e.\ $q$ is a primitive root modulo $257$. In that case $\Rq\cong\F_{q^{256}}$ and $q\mathcal{O}_K$ is a prime ideal of $\mathcal{O}_K=\Z[\zeta_{257}]$.
\end{proposition}
\begin{proof}
For $\gcd(q,m)=1$ all irreducible factors of $\Phi_m$ over $\F_q$ have degree $\mathrm{ord}_m(q)$; here $\deg\Phi_{257}=\varphi(257)=256$. The statement about $q\mathcal O_K$ is the standard description of inert primes in cyclotomic fields.
\end{proof}
Direct computation gives $\mathrm{ord}_{257}(q)=256$ for $q=2663$ ($\equiv93$), $3329$ ($\equiv245$), $3643$ ($\equiv45$) and $12289$ ($\equiv210 \pmod{257}$). Among the primes below $20000$ there are $1142$ moduli with this property. Not every NTT-friendly prime works: $\mathrm{ord}_{257}(7681)=128$, so $\Phi_{257}$ splits into two factors of degree $128$ modulo $7681$. The moduli used in this paper are $q=2663$, $3329$ and $3643$, chosen per module rank in Section~\ref{sec:params}; $3329$ is the ML-KEM modulus.

\begin{remark}[Comparison with ML-KEM]
For $q=3329$ one has $q\equiv 1 \pmod{256}$ but $q\not\equiv 1\pmod{512}$ ($3329\bmod 512=257$, $\mathrm{ord}_{512}(3329)=2$). Hence $X^{256}+1$ factors modulo $3329$ into $128$ \emph{quadratic} factors, not $256$ linear ones; this is why ML-KEM uses an incomplete, 7-layer NTT. $q=12289$, which splits $X^{256}+1$ completely, is not an ML-KEM modulus.
\end{remark}

\begin{remark}[Subfields]\label{rem:sub}
$\F_{q^{256}}$ is not ``subfield-free'': it contains the subfields $\F_{q^{2^j}}$, $0\le j\le 7$, and $\mathrm{Gal}(\F_{q^{256}}/\F_q)$ is cyclic of order $256$; likewise $\mathbb{Q}(\zeta_{257})$ has a cyclic Galois group of order $256$ and a subfield of every degree $2^j$. What differs from $X^{256}+1$ is only that $\Rq$ does not decompose as a product of smaller rings. Whether this has any security consequence is open.
\end{remark}

\paragraph{Multiplication.} Let $a,b\in\Rq$ with coefficient vectors of length $256$ (degree $\le255$). Then $ab=\sum_{i=0}^{510}c_iX^i$ over $\Z_q$. Since $\Phi_{257}\mid X^{257}-1$, first fold $p_i=\sum_{j+l\equiv i\ (257)}a_jb_l$ for $0\le i\le256$; then $ab\bmod\Phi_{257}$ has coefficients $p_i-p_{256}$ for $0\le i\le255$ (because $X^{256}\equiv-(X^{255}+\dots+1)$). Hence a ring multiplication is a length-$257$ cyclic convolution followed by $256$ subtractions.

\section{Scheme}\label{sec:scheme}
Fix $\eta=2$, module rank $k\in\{2,3,4\}$ and the modulus $q_k$ of Table~\ref{tab:params}: $q_2=2663$, $q_3=3329$, $q_4=3643$ (Section~\ref{sec:params}); we write $q$ for $q_k$. All moduli used are odd. Put $h=(q+1)/2$ and let $\mathrm{Enc}_1(m)=h\cdot m$ embed $m\in\{0,1\}^{256}$ coefficient-wise into $\Rq$. For $x\in\Rq$ let $\hat x_i\in\{0,\dots,q-1\}$ be the canonical representative of its $i$-th coefficient; then $\mathrm{Dec}_1(x)_i=1$ iff $\lceil q/4\rceil\le\hat x_i\le\lfloor 3q/4\rfloor$ (equivalently $q\le4\hat x_i<3q$).

\paragraph{PKE.}
\begin{itemize}[nosep]
\item $\mathsf{KeyGen}$: $A\leftarrow U(\Rq^{k\times k})$; $s,e\leftarrow\chi^k$; $t=As+e$. $pk=(A,t)$, $sk=s$.
\item $\mathsf{Enc}(pk,m;r)$: coins determine $r,e_1\leftarrow\chi^k$, $e_2\leftarrow\chi$; $u=A^{T}r+e_1$; $v=t^{T}r+e_2+\mathrm{Enc}_1(m)$. Output $(u,v)$.
\item $\mathsf{Dec}(sk,(u,v))$: $m'=\mathrm{Dec}_1(v-s^{T}u)$.
\end{itemize}
\textbf{Correctness.} $v-s^{T}u=\mathrm{Enc}_1(m)+E$ with $E=e^{T}r+e_2-s^{T}e_1$, where $E$ is computed with integer coefficients (before any reduction modulo $q$). By Lemma~\ref{lem:dec} below, a decoding error in coefficient $i$ forces $|E_i|\ge t_q$, where $t_q=\lfloor q/4\rfloor$ if $q\equiv1\pmod4$ and $t_q=\lceil q/4\rceil$ if $q\equiv3\pmod4$.

\begin{lemma}[Decoding]\label{lem:dec}
Let $q=4a+1$ or $q=4a+3$, $h=(q+1)/2$, $m\in\{0,1\}$, and let $E$ be an integer with $|E|\le(q-1)/2$. Then $\mathrm{Dec}_1(\mathrm{can}_q(hm+E))=m$ if and only if $E$ lies in the region
\begin{center}\small\begin{tabular}{lcc}\toprule
 & $q=4a+1$ & $q=4a+3$\\\midrule
$m=0$ & $[-a,\,a]$ & $[-a,\,a]$\\
$m=1$ & $[-a,\,a-1]$ & $[-a-1,\,a]$\\\bottomrule
\end{tabular}\end{center}
Consequently, if the decoding of a coefficient is wrong then $|E|\ge t_q$, with $t_q=a$ for $q=4a+1$ and $t_q=a+1$ for $q=4a+3$; this threshold is attained.
\end{lemma}
\begin{proof}
In both cases $\lceil q/4\rceil=a+1$ and $\lfloor3q/4\rfloor-q=-(a+1)$; moreover $h=2a+1$ for $q=4a+1$ and $h=2a+2$ for $q=4a+3$.
\emph{$m=0$.} If $E\ge0$ then $x=E$ and $\mathrm{Dec}_1(x)=0$ iff $E\le a$. If $E<0$ then $x=q+E$ and $\mathrm{Dec}_1(x)=0$ iff $q+E>\lfloor3q/4\rfloor$, i.e.\ $E\ge-a$.
\emph{$m=1$.} The integer $u=h+E$ lies in $[1,q]$; for $u=q$ we get $x=0$ and an error, and $u=q>\lfloor3q/4\rfloor$ is excluded below anyway. Otherwise $x=u$, and $\mathrm{Dec}_1(x)=1$ iff $a+1\le h+E\le\lfloor3q/4\rfloor$, i.e.\ $a+1-h\le E\le\lfloor3q/4\rfloor-h$, which gives the stated intervals.
For the consequence: if $|E|\le t_q-1$ then $|E|\le a-1$ ($q=4a+1$) or $|E|\le a$ ($q=4a+3$), so $E$ lies in both regions and the decoding is correct (also $|E|<q/2$, so no wraparound occurs). Equality is attained, e.g.\ for $m=1$, $E=a$ when $q=4a+1$, and for $m=0$, $E=a+1$ when $q=4a+3$.
\end{proof}

\paragraph{KEM ($\mathrm{FO}^{\not\perp}$).} Let $\mathcal M=\{0,1\}^{256}$, let $\mathcal R$ be the set of coin strings from which the sampler draws $(r,e_1,e_2)$ (we model the expansion of the coins into noise vectors as ideal), and let $G:\mathcal M\to\mathcal R$ and $H:\{0,1\}^{*}\to\{0,1\}^{256}$ be random oracles. This is the transformation $\mathrm{FO}^{\not\perp}=U^{\not\perp}\circ T$ of Hofheinz--H\"ovelmanns--Kiltz \cite{HHK17} applied to the PKE above (which never returns $\bot$):
\begin{itemize}[nosep]
\item $\mathsf{KeyGen}$: $(pk,s)\leftarrow\mathsf{PKE.KeyGen}$, $z\leftarrow\mathcal M$; $sk_{\mathrm{KEM}}=(s,pk,z)$.
\item $\mathsf{Encaps}(pk)$: $m\leftarrow\mathcal M$; $c=\mathsf{Enc}(pk,m;G(m))$; output $(c,\,K=H(m\,\|\,c))$.
\item $\mathsf{Decaps}(sk,c)$: $m'=\mathsf{Dec}(s,c)$; if $\mathsf{Enc}(pk,m';G(m'))=c$ (constant-time comparison) return $H(m'\,\|\,c)$, else return $H(z\,\|\,c)$ (implicit rejection).
\end{itemize}
Practical hardenings (hashing the public key into $G$, deriving $K$ from a $G$-output and $H(c)$, as in Kyber) are standard against multi-target attacks; they are \emph{not} covered by Theorem~\ref{thm:cca} below and we make no claim for them.

\paragraph{Sizes (no compression).} All three moduli are below $4096$, so $12$-bit packing applies: $|pk|=384k+32$ B, $|c|=384(k+1)$ B, $|sk_{\mathrm{KEM}}|=384k+|pk|+32$ B.

\section{Security}\label{sec:sec}
\begin{theorem}[IND-CPA]\label{thm:cpa}
For every adversary $\mathcal A$ against the PKE there are distinguishers $\mathcal B_1,\mathcal B_2$ with essentially the running time of $\mathcal A$ such that
\[
\mathrm{Adv}^{\mathrm{IND\text{-}CPA}}(\mathcal A)\le \mathrm{Adv}^{\mathrm{MLWE}}_{k,k,\chi}(\mathcal B_1)+\mathrm{Adv}^{\mathrm{MLWE}}_{k+1,k,\chi}(\mathcal B_2).
\]
\end{theorem}
\begin{proof}
\emph{Game $G_0$} is the real IND-CPA game. \emph{Game $G_1$} is $G_0$ with $t$ replaced by a uniform $t^*\in\Rq^k$. $\mathcal B_1$, given an MLWE challenge $(A,t^*)$ with $k$ samples and secret $s$, runs $\mathcal A$ on $pk=(A,t^*)$, plays the challenger honestly for the rest and outputs $1$ iff $\mathcal A$ wins. If $t^*=As+e$ this is exactly $G_0$, otherwise $G_1$, so $|\Pr[G_0]-\Pr[G_1]|=\mathrm{Adv}^{\mathrm{MLWE}}_{k,k,\chi}(\mathcal B_1)$.
\emph{Game $G_2$} replaces $(u,v)$ by uniform elements of $\Rq^k\times\Rq$. In $G_1$ the matrix $B=\binom{A^{T}}{t^{T}}\in\Rq^{(k+1)\times k}$ is uniform and
\[
\binom{u}{v-\mathrm{Enc}_1(m_b)}=B\,r+\binom{e_1}{e_2}
\]
is an MLWE sample with secret $r$ and $k+1$ rows. $\mathcal B_2$, given $(B,w)$, parses $B$ into $A^{T}$ and $t^{T}$, runs $\mathcal A$ on $pk=(A,t)$, and after the challenge messages are chosen returns $\mathcal A$ the ciphertext $(w_{1..k},\,w_{k+1}+\mathrm{Enc}_1(m_b))$. Real samples give $G_1$, uniform ones $G_2$. In $G_2$ the ciphertext is independent of $b$ so $\Pr[G_2]=\tfrac12$. Combining, $\Pr[G_0]-\tfrac12\le\varepsilon_1+\varepsilon_2$.
\end{proof}
\begin{remark}[Why no ``axiom'']
The theorem is a relative statement. It does \emph{not} give $\mathrm{Adv}^{\mathrm{IND\text{-}CPA}}=0$: an unbounded adversary recovers $s$ from $(A,t)$ (the support of $(s,e)$ is far smaller than $q^{256k}$), so no sound assumption can set the MLWE advantage of \emph{all} distinguishers to zero. Security is computational and rests on the hardness of MLWE for efficient adversaries. Any mechanised proof should formalise the inequality of Theorem~\ref{thm:cpa}, not an unconditional-hardness axiom.
\end{remark}

\begin{theorem}[IND-CCA2 in the random-oracle model]\label{thm:cca}
Let $\delta$ be any value for which Theorem~\ref{thm:chernoff} gives $\Pr[\exists i:\,|E_i|\ge t_q]\le\delta$ (for the parameter sets of this paper, the certified values of Table~\ref{tab:cert}). For every IND-CCA adversary $\mathcal B$ against the KEM above that makes at most $q_{RO}$ queries in total to $G$ and $H$ (counting the queries made implicitly in the experiment) there are distinguishers $\mathcal B_1,\mathcal B_2$ of about the same running time such that
\[
\mathrm{Adv}^{\mathrm{IND\text{-}CCA}}(\mathcal B)\;\le\; q_{RO}\,\delta+\frac{3q_{RO}}{2^{256}}+3\Big(\mathrm{Adv}^{\mathrm{MLWE}}_{k,k,\chi}(\mathcal B_1)+\mathrm{Adv}^{\mathrm{MLWE}}_{k+1,k,\chi}(\mathcal B_2)\Big).
\]
\end{theorem}
\begin{proof}
This is the concrete bound of \cite[Section~3.3]{HHK17} for $\mathrm{KEM}^{\not\perp}=\mathrm{FO}^{\not\perp}[\mathrm{PKE},G,H]$ in its IND-CPA form (combining their Theorems~3.2 and~3.4; we use the revised version of November 2021, which corrects counting errors of earlier versions), instantiated as follows. \emph{(i) IND-CPA security:} by Theorem~\ref{thm:cpa}, $\mathrm{Adv}^{\mathrm{IND\text{-}CPA}}_{\mathrm{PKE}}\le\mathrm{Adv}^{\mathrm{MLWE}}_{k,k,\chi}+\mathrm{Adv}^{\mathrm{MLWE}}_{k+1,k,\chi}$ (the definitions of the game agree: bit-guessing advantage). \emph{(ii) Correctness:} \cite{HHK17} call a PKE $\delta$-correct if $\mathbb E_{(pk,sk)}\big[\max_{m\in\mathcal M}\Pr[\mathsf{Dec}(sk,\mathsf{Enc}(pk,m))\ne m]\big]\le\delta$. For fixed keys and any $m$, by Lemma~\ref{lem:dec} a decoding error requires $|E_i|\ge t_q$ for some coefficient $i$; the probability over the coins of this event does not depend on $m$, so it bounds the maximum over $m$. Taking the expectation over the keys $(s,e)$ gives $\Pr[\exists i:\,|E_i|\ge t_q]\le\delta$, where the probability is over keys and coins jointly, as in Theorem~\ref{thm:chernoff} ($E_i$ does not depend on the matrix $A$). \emph{(iii)} $|\mathcal M|=2^{256}$, and $G$ ranges over the coin space.
\end{proof}
\begin{remark}[What the theorem says about the security level]
\cite{HHK17} state that $\kappa$ bits of security require $\delta\le2^{-\kappa}$. The certified values ($2^{-134.57}$, $2^{-143.95}$, $2^{-131.17}$ for $k=2,3,4$) therefore limit what this theorem can support through the correctness term to about $134$, $143$ and $131$ bits; we do not assign security levels. The theorem is in the classical random-oracle model: the quantum random-oracle results of \cite{HHK17} concern a variant with an additional hash $d$ in the ciphertext, which we do not use, so we make no claim in the QROM. It also gives no statement about the hardness of Module-LWE over $\Rq$ itself.
\end{remark}

\paragraph{Worst-case reductions.} Lyubashevsky--Peikert--Regev \cite{LPR13} give a quantum reduction from approximate worst-case SVP on ideal lattices to RLWE for \emph{any} cyclotomic field, hence including $\mathbb{Q}(\zeta_{257})$, but for discrete Gaussian errors in the canonical embedding with width $\alpha q\ge\omega(\sqrt{\log n})$ and with moduli and approximation factors that are polynomial in $n$ with non-trivial exponents. The parameters used here ($q\le3643$, centered binomial $\eta=2$, $n=256$) lie outside that regime, exactly as for ML-KEM, so the reductions provide asymptotic motivation only and no concrete bits of security. Moreover, for prime-power cyclotomic fields (which includes conductor $257$) there are quantum algorithms for ideal-SVP with approximation factors $\exp(\tilde O(\sqrt n))$ in certain settings \cite{CDPR16,CDW17}; these do not break RLWE at the parameters considered, but they caution against reading worst-case statements as guarantees.

\paragraph{Concrete security.} Attacks on (M)LWE (primal uSVP, BDD, dual, hybrid) as implemented in the lattice-estimator \cite{APS15} see only the instance parameters $(n,m,q,\chi_s,\chi_e)$; they do not depend on the ring structure. We ran \texttt{LWE.estimate} (default settings, October 2026) on two instances per parameter set: \emph{key recovery} ($n=256k$, $m=n$, secret and error $\psi_2$) and \emph{message recovery} (secret $r$, errors $(e_1,e_2)$: $n=256k$, $m=256(k+1)$), and, with the same call, on the corresponding ML-KEM instances (ML-KEM-512: $\psi_3$ secret and error for key recovery, $\psi_3$ secret and $\psi_2$ error for message recovery). Table~\ref{tab:est} reports the output unchanged.

We draw no ranking conclusion from differences of this size: in this model CLH-MAX is within about three bits of ML-KEM, and the ring itself plays no role in the estimates. Limitations: the estimates are for generic MLWE, they use the independence of the coordinates of $(s,e)$ built into the estimator, and we assign no NIST category. Known structural attacks (subfield attacks on overstretched NTRU \cite{ABD16,CJL16}) target large-modulus NTRU-type instances and are not known to apply to MLWE at these moduli in either ring; Remark~\ref{rem:sub} explains why the field structure of $\Rq$ is not obviously free of exploitable structure.

\section{Ring-specific security considerations}\label{sec:ringsec}
The estimates of Section~\ref{sec:sec} are generic and do not see the ring. This section checks the hypotheses of the known attacks on RLWE/PLWE that do exploit the ring. It does not prove hardness; it shows which known attack families do not apply, and why.

\begin{proposition}\label{prop:nohom}
Let $q$ be a prime with $\mathrm{ord}_{257}(q)=256$. Every ring homomorphism from $\Rq\cong\F_{q^{256}}$ to a finite field $F$ is injective; in particular $|F|\ge q^{256}$.
\end{proposition}
\begin{proof}
The kernel of a unital ring homomorphism out of a field is a proper ideal, hence zero. The image is then a subfield of $F$ with $q^{256}$ elements.
\end{proof}

\paragraph{Homomorphism-based attacks.} The attacks of Eisentr\"ager--Hallgren--Lauter \cite{EHL14}, Elias--Lauter--Ozman--Stange \cite{ELOS15} and Chen--Lauter--Stange \cite{CLS17} map RLWE samples through a ring homomorphism $\phi:\Rq\to F$ to a finite field, enumerate the possible images $\phi(s)$ and test whether the pushed-forward errors are detectably non-uniform. By \cite{CLS17}, this requires that $F$ be small enough to be enumerated, and the only ring homomorphisms from $\Rq$ to a finite field are reductions modulo primes above $q$. For our moduli the ideal $q\mathcal{O}_K$ is prime with residue degree $f=256$ (Proposition~\ref{prop:irr}), so by Proposition~\ref{prop:nohom} the only available $F$ is $\Rq$ itself and the enumeration covers all $q^{256}$ possible secrets. The running time $O(nq^{2f})$ stated in \cite{CLS17} is then about $2^{5830}$ for $q=2663$, $2^{6000}$ for $q=3329$ and $2^{6070}$ for $q=3643$. The earlier attacks \cite{EHL14,ELOS15} additionally need a root of the defining polynomial modulo $q$ (a prime of residue degree one), of small order; $\Phi_{257}$ has no root modulo $q$ because it is irreducible of degree $256$, and $\Phi_{257}(1)=257\not\equiv0\pmod q$.

\paragraph{Subfield vulnerability.} \cite{CLS17} identify a vulnerability when many elements of the basis lie in a proper subfield $K'$ of the field in which $q$ has smaller residue degree. In the power basis of $\mathbb{Q}(\zeta_{257})$, for $1\le i\le256$ the element $\zeta^i$ generates the whole field (257 is prime), and modulo $q$ each $\zeta^i$ is a root of $\Phi_{257}$, hence has degree $256$ over $\F_q$ (the $q$-th powers of $\zeta$ run over all $\zeta^i$ because $q$ generates $(\Z/257)^{*}$). Only the constant term $1$ lies in a proper subfield, one basis element out of $256$.

\paragraph{Prime-conductor attacks.} \cite{CLS17} also attack prime cyclotomic rings in two settings: (a) non-dual RLWE with modulus equal to the ramified prime $p$ (here $257$; all our moduli differ), and (b) dual RLWE with continuous Gaussian errors of width about $1/\sqrt p$ for any modulus. Our scheme is a discrete, non-dual (polynomial-basis) instance with $q\ne257$, so neither applies as stated, and \cite{CLS17} argue heuristically that modulus switching does not transfer attack (a) to other moduli. For (b), the widths attacked correspond, after the rescaling used there, to a coefficient standard deviation of about $0.3$--$0.4$ (width $\approx0.85$ in the convention $w=\sqrt{2\pi}\sigma$), against $\sigma=1$ for our noise. These are different problems and we do not claim that this settles the question: whether an adaptation of (b) to the non-dual discrete setting exists is open.

\paragraph{Contrast with ML-KEM.} In ML-KEM the available homomorphisms land in $\F_{q^2}$, which has about $2^{23}$ elements and can be enumerated; in the framework of \cite{CLS17} the protection then rests on the statistical closeness of the pushed-forward error to uniform. For CLH-MAX the enumeration step itself is infeasible. This is a statement about two known attack families, not a security comparison.

\paragraph{What this does not show.} We only checked the hypotheses of the attacks in the literature that we found; we did not carry out an exhaustive survey. Generic lattice attacks are covered by the estimates of Section~\ref{sec:sec} and worst-case/ideal-lattice algorithms by the discussion there. Absence of a known attack is not a proof of security.

\section{Correctness: decryption failure probability}\label{sec:dfp}
\begin{lemma}\label{lem:count}
For $a,b\in\Rq$ with independent coefficients, every coefficient of $ab\in\Rq$ is a signed sum of $510$ products $a_jb_l$ of distinct index pairs, except coefficient $255$ which is a signed sum of $511$.
\end{lemma}
\noindent The proof is a direct count of index pairs (Appendix~\ref{app:count}). This is roughly twice the $256$ terms of a negacyclic product, so the variance of a product coefficient is about $2\sigma^4\cdot256$ rather than $256\sigma^4$.

For module rank $k$, the coefficient $E_i$ of $e^{T}r-s^{T}e_1+e_2$ is a sum of $2k\cdot511$ products of two independent $\psi_2$ samples (a conservative count) plus one $\psi_2$ sample, with variance $\sigma_E^2=1022k+1$. By Lemma~\ref{lem:dec}, $\delta\le\sum_{i}\Pr[|E_i|\ge t_q]$. \emph{Heuristic estimate:} treating the summands as independent, we compute the exact distribution by convolution and use $\delta\lesssim256\cdot\Pr[|E_i|\ge t_q]$ (script \texttt{dfp.py}):

This estimate rests on an independence assumption between products that share a factor, which is false, so it is \emph{not} a bound. We therefore also derive a bound that needs no such assumption.

\begin{theorem}[Chernoff bound with exact moment generating function]\label{thm:chernoff}
Let $\eta=2$, extend $e$ by $e'_j=e_j$ for $0\le j\le255$ and $e'_{256}=0$, and for $0\le i\le255$ put $s=i+1$, $b_l=256-l$ and $c^{(i)}_l=e'_{(b_l+s)\bmod257}-e'_{b_l}$. For $\lambda>0$ let
\[
M_1^{(i)}(\lambda)=\mathbb E_e\Big[\prod_{l=0}^{255}\cosh\!\big(\lambda c^{(i)}_l/2\big)^{2\eta}\Big].
\]
Then, for every $\lambda>0$,
\[
\delta\;\le\;2\sum_{i=0}^{255}\exp\!\Big(-\lambda t_q+2k\ln M_1^{(i)}(\lambda)+2\eta\ln\cosh(\lambda/2)\Big).
\]
\end{theorem}
\begin{proof}
By the folding rule, the coefficient $i$ of $er$ in $\Z[X]/\Phi_{257}$ is $p_i-p_{256}$ with $p_j=\sum_{a+l\equiv j\,(257)}e'_ar_l$ over $0\le l\le255$; hence it equals $\sum_{l=0}^{255}c_lr_l$ with $c_l=e'_{(i-l)\bmod257}-e'_{(256-l)\bmod257}$, which is the stated expression because $i-l\equiv b_l+s\pmod{257}$. Given $e$, the $r_l$ are independent, and for an integer $c$ one has $\mathbb E[e^{\lambda c\,r_l}]=\cosh(\lambda c/2)^{2\eta}$ (each summand of the centered binomial has moment generating function $\cosh^2(x/2)$). Averaging over $e$ gives $M_1^{(i)}(\lambda)$ exactly, with no independence assumption between the coefficients of the product. The $2k$ products in $E$ use independent pairs of polynomials and are independent of $e_2$, whose moment generating function is $\cosh(\lambda/2)^{2\eta}$, so $\mathbb E[e^{\lambda E_i}]=M_1^{(i)}(\lambda)^{2k}\cosh(\lambda/2)^{2\eta}$. The distribution of $E_i$ is symmetric, so Chernoff's inequality bounds both tails by the same quantity, and the union bound over the $256$ coefficients does not require independence between them. Finally Lemma~\ref{lem:dec} gives $\delta\le\sum_i\Pr[|E_i|\ge t_q]$.
\end{proof}
\noindent \emph{Computing $M_1^{(i)}$.} The indices $x_t=ts\bmod257$ ($t=1,\dots,257$) run through all residues, and the $c_l$ are the differences $e'_{x_{t+1}}-e'_{x_t}$ along this path for $t=1,\dots,256$, with $x_{257}=0$. The node with index $256$ is fixed to $0$; the other $256$ nodes are independent $\psi_2$ samples. The expectation is therefore a product of $5\times5$ transfer matrices with entries $\cosh(\lambda(v-u)/2)^4$, computed exactly.

\emph{Certified evaluation.} For each parameter set we fixed a dyadic rational $\lambda$ and evaluated the bound with interval arithmetic (script \texttt{certified\_dfp.py}, \texttt{mpmath.iv}, outward rounding; the float64 script \texttt{rigorous\_dfp.py} agrees to within $0.02$ bits, and an independent evaluation with exact rational arithmetic, script \texttt{exact\_dfp\_check.py}, confirms $\delta\le2^{-134},2^{-143},2^{-131}$ for the three chosen sets). \section{Arithmetic}\label{sec:arith}
By Section~\ref{sec:ring}, multiplication in $\Rq$ is a length-$257$ cyclic convolution followed by a correction (the folding rule), which we verified against the explicit reduction modulo $\Phi_{257}$. Schoolbook multiplication costs $256^2=65{,}536$ coefficient products per ring multiplication; Karatsuba needs $3^8=6{,}561$ products on $256$ coefficients. $\mathsf{KeyGen}$ needs $k^2$ ring products for $As$ and $\mathsf{Enc}$ needs $k^2+k+k$ more.

\paragraph{No NTT modulo $q$.} A transform modulo $q$ covering the linear convolution needs $512\mid q-1$, which fails for all three moduli: $2662=2\cdot11^3$, $3328=2^8\cdot13$ and $3642=2\cdot3\cdot607$.

\paragraph{NTT over an auxiliary prime.} Every product in the scheme has one small operand ($s$, $r$ or $e_1$, with coefficients in $[-2,2]$). The integer coefficients of such a product are bounded by $256\cdot\lfloor q/2\rfloor\cdot2\le932{,}352$ for $q\le3643$ (centered representatives). Hence the product can be computed exactly with a $512$-point NTT over any prime $P\equiv1\pmod{512}$ with $P>2\cdot932{,}352$: lift the result to centered integers, fold as above and reduce modulo $q$. We verified this against the explicit reduction for all three moduli with $P=469762049=7\cdot2^{26}+1$. By butterfly count, one $512$-point transform has $9\cdot256=2304$ butterflies, against $7\cdot128=896$ for the incomplete $256$-point transform of ML-KEM, i.e.\ about $2.6$ times more, and the arithmetic is wider ($29$-bit instead of $12$-bit). In a matrix-vector product the transforms of the small vector are computed once and the inverse transforms are shared. A modulus with a native NTT does not help: for $q=12289$ ($512\mid q-1$, $\mathrm{ord}_{257}(q)=256$) and $k=2$, reaching $\beta_{\mathrm{uSVP}}\ge398$ (the level of CLH-MAX-512) requires $\eta=11$ ($\beta_{\mathrm{uSVP}}=403$ in our calibrated model), and the Chernoff bound then gives $\delta\approx2^{-98}$ (script \texttt{compression\_\allowbreak dfp.py}): the larger noise needed for the same security destroys correctness. We did not benchmark an implementation and make no performance claim; the reference implementation of Appendix~\ref{app:script} is written for clarity, not speed, and is not constant-time.

\section{Open problems}
(i) Tighter rigorous bounds on $\delta$ (the Chernoff bound of Section~\ref{sec:dfp} is $9$--$14$ bits weaker than the heuristic estimate, so a sharper method would allow smaller moduli) and a finer exploration of compression settings (the ML-KEM settings we tested break $\delta$, so our ciphertexts are $22$--$50\%$ larger than ML-KEM's). (ii) Narrowing the residual gap of about three bits at $k=4$: asymmetric noise does not help (Section~\ref{sec:params}); other noise distributions are untested, e.g.\ with other $(\eta,q)$ or with different noise for secret and error. (iii) An optimised, constant-time implementation and benchmarks (e.g.\ with an NTT over an auxiliary prime). (iv) A complete ring-specific cryptanalysis: Section~\ref{sec:ringsec} only checks the hypotheses of known attacks; in particular, whether an adaptation of the dual-RLWE narrow-error attack of \cite{CLS17} to the non-dual discrete setting exists, and whether the order-$256$ Galois action of $\Rq$ gives any algebraic leverage against MLWE. (v) A machine-checked proof of the Fujisaki--Okamoto transform (IND-CCA2) and of the statements that involve the hardness assumption; the Lean files cover only the IND-CPA game-hopping inequality.

\section{Proof of Lemma~\ref{lem:count}}\label{app:count}
Coefficient $i$ of $ab\bmod\Phi_{257}$ is $p_i-p_{256}$ with $p_i=\sum_{j+l\equiv i\ (257)}a_jb_l$, $0\le j,l\le255$. For $0\le i\le255$: pairs with $j+l=i$ number $i+1$, and pairs with $j+l=i+257$ number $255-(i+2)+1=254-i$ (for $i\le254$) and $0$ for $i=255$. So $p_i$ has $255$ terms for $i\le254$ and $256$ terms for $i=255$. For $p_{256}$: $j+l=256$ gives $255$ pairs ($j=1,\dots,255$); $j+l=513>510$ is impossible, so $p_{256}$ has $255$ terms. The index-pair sets of $p_i$ and $p_{256}$ are disjoint, hence the coefficient is a signed sum of $255+255=510$ products, or $256+255=511$ for $i=255$. $\square$

\paragraph{Decryption failure probability} (exact convolution under the independence heuristic; $e,s,r\leftarrow\psi_{\eta_1}$, $e_1,e_2\leftarrow\psi_{\eta_2}$; threshold $t_q$ of Lemma~\ref{lem:dec}).
\begin{verbatim}
import numpy as np
from math import log2, comb
def cbd(eta):
    return np.array([comb(2*eta, i) for i in range(2*eta+1)], float)/4**eta, eta
def prod_pmf(x, y):
    p1, o1 = cbd(x); p2, o2 = cbd(y); d = {}
    for i, a in enumerate(range(-o1, o1+1)):
        for j, b in enumerate(range(-o2, o2+1)):
            d[a*b] = d.get(a*b, 0) + p1[i]*p2[j]
    off = max(abs(v) for v in d); arr = np.zeros(2*off+1)
    for v, p in d.items(): arr[v+off] += p
    return arr, off
def conv_pow(p, off, m):
    res, roff, base, boff = np.array([1.0]), 0, p.copy(), off
    while m:
        if m & 1: res = np.convolve(res, base); roff += boff
        m >>= 1
        if m: base = np.convolve(base, base); boff *= 2
    return res, roff
def delta(k, eta1, eta2, q):
    thr = q // 4 if q % 4 == 1 else (q + 1) // 4      # t_q of Lemma 1
    pa, oa = prod_pmf(eta1, eta1); pb, ob = prod_pmf(eta1, eta2)
    d1, o1 = conv_pow(pa, oa, k*511); d2, o2 = conv_pow(pb, ob, k*511)
    d, o = np.convolve(d1, d2), o1 + o2
    p2, oo = cbd(eta2); d, o = np.convolve(d, p2), o + oo
    idx = np.arange(len(d)) - o
    t = d[np.abs(idx) >= thr].sum()
    return log2(t), log2(t) + 8           # per coefficient, union over 256
for k, e1, e2, q in [(2,2,2,2663), (3,2,2,3329), (4,2,2,3643), (4,2,2,3329)]:
    print(k, e1, e2, q, delta(k, e1, e2, q))
\end{verbatim}
